# Andrea Sofia

**Full Stack Web Developer** based in Rome · **Agentic Engineering** with Claude Code · AI integrations

### How I work
I work **agentically**: AI agents (Claude Code) write and verify the code, and I direct the work. I own the architecture and
the rules, run checks before and after every release, and I'm accountable for what runs in production.

### Projects
- **[wp-doctor](https://github.com/andrea-sofia-dev/wp-doctor)** · [try it online](https://wp-doctor.vercel.app):
  PageSpeed tells you the server is slow; wp-doctor tells you why, and whether real visitors get the cache
  (consent cookie, utm_* links, phones). CLI, web app and MCP server, so an AI agent can run the checks and
  propose fixes. When a site refuses plain requests, it checks again through a real browser.
- **[WordPress performance case study](https://github.com/andrea-sofia-dev/wordpress-performance-case-study)**:
